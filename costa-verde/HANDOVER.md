## The project
An original GTA-style open-world crime game on Roblox, set in a fictional Florida-like state, 16+ (not 18+).
No copied IP: no real brands, no GTA assets, original designs only. Everything is generated by code, tuned on
real public data (USGS terrain, Census TIGER roads, Census business counts, FEMA building footprints).

## How the user wants to work
- Realism from real data, never guesses ("be realistic to real cities, no assumptions").
- Show progress with screenshots (send them); keep renders cheap: **one quick render per change**, no long
  full-quality renders unless asked.
- Commit and push after each step to the branch above.
- Be honest about limits; audit your own work for mistakes before reporting.
- Cars: the user will import free Sketchfab cars (CC-BY) and credit authors on the start screen
  (`screenshots/sketchfab_shortlist.png`; picks: Generic passenger car pack, Generic civil service vehicles pack,
  Shvan '92, Lightbody Lifted '85, Kiri '86, LCT 3000 '07). Downloading needs the user's Sketchfab API key.

## What exists (see ROADMAP.md for detail)
- **Map generator** (`src/shared/Gen/`, Luau, runs in Roblox and Lune): terrain, coast, keys, districts, whole-map
  road network (freeways with interchanges, arterials, local streets, rural roads), rail/metro, 200 landmarks,
  ~12.5k buildings with real footprint sizes/shapes, uses and map markers. `lune run tools/export-world.luau`
  writes `build/world.json`; `python3 tools/audit_world.py` checks it (all pass except big downtown buildings
  being ~half real size: known gap).
- **Roblox builders** (`src/shared/`): `TerrainBuilder` (4-stud voxel terrain, materials, ditches, canals, levees,
  seawalls), `Vegetation` (models from `tools/blender/make_assets.py`, FBX in `assets/roblox/`), `WorldBuilder`
  (greybox roads/buildings, skips the detailed block), `LightingPreset` + day/night server script.
- **Detailed test block** (old town at generator coords 27740, 23180, radius 380): `tools/blender/detail_town.py` +
  `tools/blender/realism.py`. Every building fully modelled with real interiors, shop interiors by business type,
  CC0 photo materials (ambientCG, `tools/fetch_cc0.py`, files gitignored), land cover (lots, fences, parks),
  Florida plants, palms, oaks with leaf cards, props, utility poles and wires, generated cars, time-of-day
  presets. Preview: `python tools/blender/detail_town.py --real --quick --hero [--time=night|dusk|golden|rain]`
  -> `screenshots/hero_<time>.png` (four eye-level shots on one sheet).

## Current step: put the detailed block into Roblox Studio
Already exported and verified (positions within 0.004 studs, all meshes under 20k triangles):
- `assets/roblox/block/`: 76 building FBX + baked JPG textures (export: `python tools/blender/export_block_roblox.py`, ~3 min)
- `assets/roblox/block/env/`: street-level surfaces, props/plants/trees/cars FBX, `leaf.png`
  (export: `python tools/blender/export_block_env.py`, <1 min; then `python tools/blender/check_block_export.py`)
- Loader `src/shared/BlockImporter.luau` (+ `BlockManifest.luau`, `BlockEnvManifest.luau`, `BlockTextures.luau`),
  night room lights `src/server/BlockLights.server.luau`.

Studio steps (the loader has never been run yet, expect fixes):
1. Install Rojo (Aftman/Rokit) + the Rojo Studio plugin; `rojo serve` in `costa-verde/` (`default.project.json`), connect in Studio.
2. 3D-import `assets/roblox/block/*.fbx` into `ReplicatedStorage.BlockAssets` and `assets/roblox/block/env/*.fbx`
   into `ReplicatedStorage.BlockEnvAssets` (keep file names as object names).
3. Upload the JPGs and `env/leaf.png`; paste ids into `src/shared/BlockTextures.luau` (`b674 = "rbxassetid://..."`, `leaf = ...`).
4. Command bar: `require(game.ReplicatedStorage.Shared.BlockImporter).place()`, then save the place.
5. Optional whole map: TerrainBuilder.build(), Vegetation.build(), WorldBuilder.build(), LightingPreset.apply() (see ROADMAP).
Unverified risks: how the importer names multi-material parts (loader matches `_opaque/_glass/_lamp` and `leaf`),
whether untextured models keep their colours, performance of ~4.3k placed models.
